## Loom V0.2.0

This is the first refactored Loom release. It publishes the desktop workbench,
standalone daemon/CLI runtime, and Plugin SDK with aligned `V0.2.0` metadata and
the existing provenance, SBOM, checksum, and smoke-verification gates.

### Highlights

- Keeps the daemon-first runtime, desktop shell, CLI, and Plugin SDK packages
  version-aligned at `0.2.0`.
- Preserves the framework-first Art bridge and the hardened plugin/security
  boundaries from the refactored codebase.
- Uses the reproducible tagged-release workflow with draft-first publication and
  exact asset verification.

### Package notes

The release contains the Windows desktop archive, CLI archive, Plugin SDK archive,
checksums, SBOMs, provenance metadata, and the release manifest.
