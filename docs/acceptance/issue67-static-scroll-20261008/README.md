## 修复与回归

1. 夹具启动时直接选择真实绘制模式，移除不必要的前台激活和模式按键注入；保留进程创建时间、路径、HWND owner 及状态核验。原历史激活失败的具体 Win32 分支没有保留下来，不伪称已精确还原。
2. 加入检查区分静态/动态：静态允许保留同一有效帧，但仍严格核验会话、epoch、编码、尺寸、连接、完整图像和实际渲染证据；滚动/运动仍要求帧号推进。
3. 源端观察器最终等待不再成为一个新采样间隔，避免提前唤醒后发起超短预算的额外 RPC。离线可控时钟复现旧失败并验证修复，真正请求超时仍然失败。
